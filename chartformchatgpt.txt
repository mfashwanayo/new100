Installation
1. Back up your project and database first.

2. Extract the ZIP into:

C:\xampp2\htdocs\UTUNYANGEbyGPT

Merge the folders and keep your existing .env and Stage 2 authentication files.

3. Import the database migration.

Open XAMPP and start MySQL.

Open phpMyAdmin.

Select utunyange_school.

Import:

database/migrations/004_stage4.sql

4. Start the project in PowerShell:

cd C:\xampp2\htdocs\UTUNYANGEbyGPT
npm run dev
